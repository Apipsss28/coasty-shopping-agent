# 🛒 Coasty AI Shopping Assistant

**AI-powered shopping agent — compares prices, reads reviews, recommends the best deal**

> "Research across live interfaces, gather evidence, and turn it into something useful end to end." — Coasty Dev

## What It Does

Searches multiple marketplaces in real-time:

1. 📦 **Amazon** — product listings & prices
2. 🏷️ **eBay** — auctions & deals
3. 🛍️ **Google Shopping** — price comparison
4. 🏪 **Best Buy** — electronics
5. ⭐ **Reviews** — sentiment analysis
6. 🧠 **Coasty AI** — smart recommendation

## Quick Start

```bash
export COASTY_API_KEY="sk-coasty-..."
pip install requests

python shopping.py "iPhone 16 Pro"
python shopping.py "Sony headphones" --budget 300
```
